# Password Strength Checker

This project is a Python-based Password Strength Checker. It analyzes a password and classifies it as Weak, Medium, or Strong based on various security criteria such as length, uppercase letters, lowercase letters, numbers, and special characters.

## Features
- Password length validation
- Uppercase letter check
- Lowercase letter check
- Number check
- Special character check
- Strength classification (Weak/Medium/Strong)

## Technologies Used
- Python
